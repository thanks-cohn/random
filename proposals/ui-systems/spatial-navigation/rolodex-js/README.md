# Rolodex.js

Project-level proposals for **Rolodex.js**, the spatial navigation and persistent-path UI system.

Canonical implementation repository:

- https://github.com/thanks-cohn/rolodex.js

Rolodex.js proposals belong here when they concern the direction, architecture, interaction vocabulary, public API, or reusable role of the library itself.

Feature proposals that merely *use* Rolodex.js should remain in their own domain and link back here when appropriate.
